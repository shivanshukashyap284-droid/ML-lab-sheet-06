# Project 2 - House Price Prediction System

## Run in VS Code

Open this folder in VS Code and run:

```bash
pip install -r requirements.txt
python house_price_prediction.py
```

The project creates a sample housing dataset using:
- Area
- Bedrooms
- Bathrooms
- Parking
- Property age
- Location

Models compared:
- Linear Regression
- Random Forest Regression
- Gradient Boosting Regression

Metrics:
- MAE
- RMSE
- R2 Score

The program also predicts the price of a new house.
